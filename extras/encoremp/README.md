# EncoreMP companion content

This directory contains optional EncoreMP ESP files supplied with the ArenaMP source tree. They are game-content choices rather than prerequisites for compiling the engine. Original authorship and the source descriptions under `docs/` are retained.

| File | Purpose |
|---|---|
| `EncoreMPV093.ESP` | Main companion plugin |
| `EncoreMPV093newcontent.ESP` | Optional race, birthsign, script and content changes |
| `EncoreMPV093Spells1Base.ESP` | Base-game spell package |
| `EncoreMPV093Spells2TRcore.ESP` | Base game and Tamriel Rebuilt core spell package |
| `EncoreMPV093Spells3TRall.ESP` | Extended Tamriel Rebuilt spell package |

Use only one `EncoreMPV093Spells*` file. The server operator chooses the supported plugins; every client must use the same list and order. The accompanying EncoreMP documents describe that upstream content and do not override ArenaMP's current code or server configuration.

## Русский

Плагины необязательны для компиляции. Подключайте набор владельца сервера и только один вариант `EncoreMPV093Spells*`. Оригинальные описания EncoreMP сохранены как документы этого контента, а не история публичных выпусков ArenaMP.
