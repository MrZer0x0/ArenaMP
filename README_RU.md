# ArenaMP

**[English](README.md) | [Русский](README_RU.md)**

ArenaMP — многопользовательский Morrowind для **Windows x64 и Linux x86_64, включая Steam Deck**. Проект основан на OpenMW, TES3MP и EncoreMP и объединяет собственный лаунчер, выделенный сервер, боевые правила, голосовую связь, жильё и экономику.

Это **первая публичная версия исходников**. В репозитории находятся клиент, настольный лаунчер, нативный обновлятор, сервер, Lua-скрипты и ресурсы проекта. Сборку можно выполнить через GitHub Actions или локально. Игровые данные Morrowind нужно взять из своей установленной игры.

[Сборка и публикация](docs/BUILDING_RU.md) · [Лаунчер](docs/LAUNCHER_RU.md) · [Документация](docs/guide/INDEX.md) · [Описание выпуска](CHANGELOG.md)

## Состав проекта

| Компонент | Назначение |
|---|---|
| Клиент ArenaMP | Сетевой мир, бой, интерфейс, анимации и интеграция голоса |
| Настольный лаунчер | Настройка игровых данных, список серверов, подключение, локальный сервер, чат и параметры |
| Выделенный сервер и CoreScripts | Персонажи, сохранение мира, группы, жильё, экономика и администрирование |
| Нативный обновлятор | Обновление клиента и контента по манифестам владельца сервера |
| Серверный и relay-агенты | Регистрация сервера в списке и соединение через совместимый мастер-сервис |
| Rubic0n LuaJIT | Встроенные исходники Lua-окружения в `extern/LuaJIT`, используемые для обеих платформ |

## Лаунчер

Лаунчер объединяет подготовку игры, подключение и управление своим сервером. В Windows запускайте `arenamp-launcher.exe`, в Linux — обёртку `arenamp-launcher` из готового пакета.

### Подготовка игровой сборки

Укажите папку с `Morrowind.esm` и плагинами выбранного сервера. Мастер настройки читает существующий `build.ini` либо создаёт его по названию сборки, языку и указанному порядку плагинов. Он находит BSA-архивы и распознаёт плагины травы. При подготовке контента можно выбрать русскую, английскую или польскую кодировку.

Раздел **Файлы данных** позволяет выбрать плагины и порядок загрузки. В разделах графики и остальных настроек доступны параметры изображения, рендера, звука и дополнительные опции. Сборка и параметры подключения сохраняются между запусками. Перед сменой сборки остановите локальный сервер.

### Поиск сервера и подключение

- Список серверов открывается внутри лаунчера и обновляется по кнопке.
- В таблице видны название, сборка, режим, число игроков и способ соединения.
- Можно открыть сайт сервера и посмотреть требования и список файлов, предоставленные владельцем.
- Поддерживается поиск приватного сервера по ID приглашения, если это предусмотрено мастер-сервисом.
- Можно выбрать прямое соединение или туннель через встроенный relay-агент, если сервис его предоставляет.
- Для подключения по известному адресу доступны ручной ввод хоста и порта.

Карточка подключения показывает адрес выбранного сервера, состояние, число игроков и время работы, когда сервер отдаёт эти сведения. Для защищённого сервера запрашивается игровой пароль. Выберите сервер, подготовьте совпадающий набор контента и нажмите **Играть**.

### Собственный сервер

Лаунчер запускает и останавливает комплектный выделенный сервер и показывает его консоль в своём окне. Можно задать имя, пароль, лимит игроков, порт и сетевой интерфейс. Доступны настройки режимов CO-OP/MMO, сгруппированные игровые параметры и редактор исходного `config.lua`.

В консоли есть выбор кодировки журнала и автоматический перезапуск. Лаунчер умеет пересчитать обязательные хеши плагинов сервера по выбранной сборке. Очистка сохранённых ячеек и полный сброс данных выполняются отдельными действиями с подтверждением; перед ними нужна резервная копия мира.

Опция **Показывать в списке серверов** регистрирует запущенный сервер в совместимом мастер-сервисе. К записи можно добавить ссылку на сайт или сборку. Прямому соединению нужны доступные сетевые порты, а туннелю — работающий relay-сервис. Публикация записи не настраивает роутер и брандмауэр.

### Чат, микрофон и обновление

Раздел **Чат** подключается к совместимому серверу с уже созданным игровым персонажем. Он показывает доступные каналы, историю сообщений, присутствие игроков, упоминания и позволяет открыть `Chat.log`. Сначала создайте персонажа в игре, затем используйте его учётную запись в лаунчере.

В настройках микрофона выбираются устройство записи, разрешение передачи и голосовая клавиша. В игре доступны локальное и групповое общение согласно правилам сервера.

Лаунчер проверяет обновления по манифесту выбранной сборки и запускает нативный обновлятор. В отдельном окне отображаются этапы загрузки и установки, проверяются заданные хеши. Владелец сервера должен настроить URL и разместить манифесты: одна публикация в GitHub Releases не подключает игровое автообновление. Подробности — в [руководстве обновлятора](docs/arena-updater/README_RU.md).

## Игровые системы

Бой объединяет активный блок и парирование, быстрый каст, расход стамины и развитие персонажа с оружием, навыками и эффектами Morrowind. Предусмотрены многоуровневая панель быстрого доступа и сетевые анимации.

Группы связывают общение, метки и доступные точки Возврата. Система жилья поддерживает владение, правила доступа, личные интерьеры, размещение мебели и витрины с ценами. Серверные модули предоставляют коэффициенты торговли, региональные рынки, ремесло, зачарование и административные инструменты. Правила зависят от настроек и контента конкретного сервера.

| Клавиша по умолчанию | Действие |
|---|---|
| W A S D | Движение |
| E | Активация; в поддерживаемых контекстах используется и удержание |
| Левая / правая кнопка мыши | Атака или применение / инвентарь |
| F | Подготовка оружия; активная защита с подходящей экипировкой |
| R | Быстрый каст; удержание — подготовить магию |
| 1–9, 0 | Быстрые назначения |
| F1 | Редактор быстрых назначений |
| V | Управление передачей голоса |
| Z | Меню анимаций |

Сохранённые привязки могут отличаться. Подробности: [управление](docs/guide/02-controls.md), [бой](docs/guide/03-combat.md), [игровые системы](docs/guide/04-gameplay.md).

## Сборка и автоматическая публикация

1. Скопируйте содержимое `ArenaMP/` в корень своего GitHub-репозитория, включая `.github` и исходники зависимостей.
2. Включите GitHub Actions и отправьте коммит в `main`/`master` либо откройте **Actions → Build and release (Windows, Linux) → Run workflow**.
3. При ручном запуске выберите Windows, Linux или обе платформы. Пакеты собираются в конфигурации **Release**.
4. После успешной сборки и проверок всех выбранных платформ workflow автоматически разместит результат во вкладке **Releases**.

К выпуску прикладываются Windows ZIP и/или переносимый Linux-архив, исходники репозитория на том же коммите, сведения о сборке и SHA-256. При ошибке или отмене выбранной сборки выпуск не публикуется. Для тега `v*` используется его имя; остальным запускам присваивается уникальный тег `build-<номер>-<попытка>`.

[Руководство по сборке](docs/BUILDING_RU.md) содержит требования, локальные команды и настройки репозитория. [Статус проверки](PACKAGE_STATUS.md) описывает границы проверки исходников и необходимые игровые испытания.

## Совместимость и сохранения

Используйте клиент и сервер одной ревизии ArenaMP, одинаковые плагины и порядок загрузки. Идентификатор протокола задаётся в [Version.hpp](components/openmw-mp/Version.hpp). Общее происхождение с TES3MP не гарантирует сетевую совместимость разных форков.

Храните рабочие учётные записи, мир и настройки владельца отдельно от публичных исходников. Перед развёртыванием делайте копию всей папки данных сервера. См. [руководство сервера](docs/guide/05-server.md).
