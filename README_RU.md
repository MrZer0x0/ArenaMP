# ArenaMP — любимый Morrowind как общий живой мир

**Русский** · **[English](README.md)**

[Состав публичного Windows/Linux-репозитория](PUBLIC_REPOSITORY.md) · [Сборка и публикация](docs/BUILDING_RU.md)

ArenaMP — самостоятельный многопользовательский проект на базе **OpenMW, TES3MP и EncoreMP**. Его цель — сделать Morrowind удобным для совместной игры и развивать его в сторону полноценного MMO: постоянного мира, в котором персонажи растут, объединяются в группы, покупают дома, обустраивают их, торгуют и создают собственную историю.

Мы хотим сохранить главное в Morrowind — свободу путешествий, необычный мир, магию и развитие героя — и добавить то, что нужно общему миру: понятный запуск, общение, сохраняемую собственность и проверяемые сервером правила. Лаунчер, игровой интерфейс и управление сервером входят в один проект, чтобы меньше времени уходило на подготовку и больше — на саму игру.

**MMO — направление развития проекта, а не обещание определённого числа игроков.** ArenaMP уже содержит системы постоянного многопользовательского мира; вместимость конкретного сервера зависит от его оборудования, контента, скриптов и нагрузки. Небольшое кооперативное приключение также остаётся поддерживаемым сценарием.

Этот публичный репозиторий предназначен для **Windows x64 и Linux x86_64**, включая переносимую сборку для Steam Deck. GitHub Actions собирает и публикует только эти две платформы. Этот архив содержит исходники и ресурсы ArenaMP, а оригинальные игровые данные Morrowind устанавливаются отдельно. Проект независим от Bethesda и не является официальным выпуском OpenMW или TES3MP.

| Задача | Возможности ArenaMP |
|---|---|

| Развивать героя | Опыт, распределение очков, архетипы, активная защита и быстрый каст |
| Обосноваться в мире | Покупка недвижимости, личные интерьеры, совладельцы, друзья и правила доступа |
| Создать свой интерьер | Магазин мебели с предпросмотром, размещение, вращение, хранение и витрины |

## Быстрый старт

### Игроку

1. Возьмите готовую **Release-сборку**, опубликованную сопровождающим проекта во вкладке GitHub **Releases**, и распакуйте полностью в папку с правами записи.
2. Запустите `arenamp-launcher.exe` в Windows либо комплектный скрипт `./arenamp-launcher` в Linux. Переносимый Linux-пакет нужно запускать через обёртку для корректной загрузки Qt и библиотек.
3. Укажите каталог легально установленного Morrowind с `Morrowind.esm`, файлами данных и модификациями, которые требует сервер.
4. Создайте профиль сборки или откройте существующий `build.ini`, выберите плагины и проверьте **точный порядок загрузки**.
5. В лаунчере откройте список серверов, выберите совместимый сервер, при необходимости введите пароль и нажмите **Играть**. Можно также подключиться по адресу вручную или запустить собственный сервер.

Один только одинаковый движок не гарантирует вход: сервер может потребовать дополнительные ESM/ESP, BSA, определённые версии контента и корректные хеши.

### Администратору сервера

В комплекте есть выделенный сервер с `server/` и CoreScripts. Настройте имя, порт, сетевой интерфейс, пароль, лимит игроков, режим, обязательные плагины, правила игры, регистрацию в списке и хранение данных. Управлять локальным сервером можно из лаунчера или через отдельный исполняемый файл. Перед обновлениями и сбросами **делайте резервную копию** персонажей, мира, домов и размещённой мебели. Лаунчер не открывает порты маршрутизатора автоматически.

### Разработчику

Разместите содержимое `ArenaMP/` в корне Git-репозитория: `CMakeLists.txt`, `.github/`, `CI/`, `apps/`, `components/`, `extern/`, `files/`, `server/` и `docs/` должны лежать рядом. Основная эталонная процедура сборки находится в GitHub Actions. Читайте [инструкции по сборке](docs/BUILDING_RU.md); вместо включённого Rubic0n LuaJIT использовать обычный системный LuaJIT не нужно.

## Лаунчер — подробно

Единый нативный лаунчер — основная точка запуска игры и управления сервером. **Не удаляйте из готового пакета** обновлятор, сервер, агент подключения, Qt-библиотеки и ресурсы, даже если не планируете пользоваться всеми функциями.

### Установка игровой сборки и плагины

При первом запуске укажите папку Morrowind либо `Data Files`. Мастер может прочитать готовый `build.ini` или создать профиль с именем сборки, выбранным языком контента, плагинами и их порядком. Учитываются исходные ESM/ESP, BSA-архивы и распознаваемые плагины травы. Кодировки для русских, польских и западных данных выбираются отдельно от языка сообщений сервера. Профили и настройки сохраняются.

Раздел **Файлы данных** управляет активными плагинами и порядком загрузки. В графике и настройках находятся параметры изображения, звука, интерфейса и другие возможности клиента. Если поменяли содержимое сборки, обновите список обязательных плагинов и хешей на сервере. Перед сменой профиля остановите запущенный локальный сервер.

### Список серверов и вход

На главной странице размещён обновляемый список серверов совместимого мастер-сервиса. В нём могут отображаться название, игровая сборка, режим, число игроков и доступные способы соединения. Карточка выбранного сервера показывает предоставленные им сведения о состоянии, времени работы, требованиях, адресе сайта/сборки и наличии пароля. Закрытый сервер можно найти по ID приглашения, если это поддерживает сервис. Подключиться по известному IP и порту можно вручную.

**Прямое соединение** требует доступного игрового порта. **Relay-соединение** использует комплектный агент и соответствующую службу, когда она доступна. Публикация сервера в списке не заменяет настройку роутера и брандмауэра и не гарантирует наличие всех нужных файлов игры.

### Свой сервер в одном окне

В разделе **Локальный сервер** можно задать название, пароль, максимальное количество игроков, порт и интерфейс; выбрать правила CO-OP/MMO; настроить игровые параметры через удобные группы или отредактировать `config.lua` напрямую. Есть запуск/остановка процесса, встроенная консоль, просмотр логов, кодировка вывода и автоматический перезапуск. Список обязательных файлов пересчитывается по текущей игровой сборке.

Переключатель **Показывать в списке серверов** регистрирует работающий сервер в совместимом мастер-сервисе. Можно указать ссылку на страницу сервера или сборку. Очистка ячеек и полный сброс данных — отдельные операции с подтверждением. При резервном копировании сохраняйте вместе мир, данные домов и реестры мебели.

### Чат, микрофон и автообновление

Раздел **Чат** поддерживает вход с учётной записью персонажа, уже созданного в игре, каналы, историю, список игроков, уведомления и открытие `Chat.log`. Настройки микрофона позволяют выбрать устройство ввода, управлять передачей голоса и назначить клавишу. В игре голосовая связь может работать локально и внутри группы с учётом правил сервера.

Нативный обновлятор использует **манифест выбранной сборки**, показывает процесс загрузки/установки и проверяет заданные хеши файлов. Владелец сервера должен сам разместить манифест и указать URL. Простая публикация архива в GitHub **не включает автоматически обновление игровых клиентов**. Дополнительные сведения — в [руководстве обновлятора](docs/arena-updater/README_RU.md).

## Игровые механики и удобство

### Создание персонажа и развитие

Обучение знакомит с особенностями ArenaMP перед началом приключения. Выбор расы и архетипа помогает определить роль героя; интерфейс показывает их особенности. Развитие использует опыт и очки для навыков и характеристик. В проекте предусмотрены уровни до 150, а награды и ограничения задаются сервером.

Серверные проверки следят за разрешённой прогрессией, очками и сохранённым состоянием героя. Настройки кооператива могут отличаться от правил постоянного MMO-сервера. Это не отменяет необходимость настроить администраторов и права доступа к серверу.

### Бой, магия и экипировка

Сохраняются навыки, атрибуты, сопротивления, зачарования и эффекты Morrowind. Поверх них работают активная защита и парирование, быстрый каст, подготовка магии, серии ударов и отображение боевой информации. Выносливость, экипировка, навыки и разница уровней участвуют в правилах боя; PvE и PvP могут иметь разные ограничения урона.

Короткое нажатие **R** использует быстрый каст, удержание — подготовку магии. Доступный способ зависит от занятых рук и оружия. **F** управляет готовностью оружия и поддерживаемой активной защитой; лук и арбалет имеют собственные состояния. Призывы подчиняются ограничениям сервера, а призванные предметы нельзя использовать как обычный источник сохраняемого имущества.

Условия смерти, восстановления, награда за голову и штрафы настраиваются сервером. Численные формулы и пределы описаны в [руководстве по бою](docs/guide/03-combat.md); они не являются гарантированным уроном каждого удара.

### Управление и быстрый доступ

| Клавиша по умолчанию | Действие |
|---|---|
| W / A / S / D | Движение |
| E | Активация; удержание — дополнительные действия в поддерживаемом контексте |
| F | Готовность оружия и активная защита с подходящей экипировкой |
| R / удержание R | Быстрый каст / подготовка магии |
| 1–9, 0 | Быстрые назначения |
| F1 | Настройка быстрых назначений |
| V | Управление передачей голоса |
| Z | Меню анимаций |

Личные назначения имеют приоритет. Быстрая панель содержит десять колонок; дополнительные ряды открываются по мере развития, каждые 30 уровней, до шести рядов. Удержание цифры позволяет изменить назначение. Для поддерживаемых замков и ловушек есть подготовка подходящего инструмента с восстановлением допустимой экипировки после применения. Подробности — [управление](docs/guide/02-controls.md).

### Группы, общение и путешествия

Пригласите спутника в группу через игровой интерфейс. Группы объединяют список участников, метки, голос и правила союзников. Синхронизация журнала и тем диалога включается отдельно: обычное вступление не должно принудительно менять прохождение. Награды за подходящие совместные действия распределяются по правилам сервера.

Возврат может предложить собственную Пометку и доступные точки участников группы. Сервер проверяет состав группы, присутствие игрока и запреты путешествий. Чат поддерживает игровые и внеигровые каналы, а голос — локальное и групповое общение. Индикация микрофона помогает видеть состояние передачи.

### Недвижимость: собственный дом в общем мире

Удержание активации подходящей двери открывает действия с недвижимостью. Для свободного объекта показываются цена и условия покупки, для принадлежащего игроку — владелец и доступные действия. Обычный вход и вход в личный экземпляр различаются; предпочтение входа настраивается.

Вкладка **«Мой дом»** позволяет управлять названием, совладельцами, друзьями, замком и правилами посетителей, а также доступными операциями передачи и продажи. Несколько связанных помещений могут относиться к одному объекту. Личный экземпляр сохраняется отдельно и защищается от обычного сброса ячеек; исходный интерьер продолжает жить по правилам мира. Для специальных объектов администратор может выбрать режим исходной ячейки.

Базовые минимальные уровни: дом — **10**, таверна — **15**, магазин — **20**, гильдейское помещение — **25**. По умолчанию действует общий предел в один объект; сервер может изменить доступность типов, лимиты и цены. Возможность читать книгу не означает право забрать её: для гостей, друзей и совладельцев действуют разные разрешения. Закрытая дверь не лишает доверенного игрока его прав.

### Мебель, оформление и витрины

Магазин мебели находится в интерфейсе игрока; доступна также команда `/furniture`. Выбирайте категорию и стиль, просматривайте модель, покупайте и размещайте предметы. Поддерживаются перемещение, вращение, возврат в мебельный инвентарь и разрешённые операции продажи/удаления. Уже купленная мебель из временно отключённого мода остаётся в учёте, но для отображения модели нужен соответствующий контент.

Поставляемая база содержит **515 записей** с отдельными названиями на русском и английском. Это справочник, а не обещание 515 товаров на любом сервере: магазин проверяет активные плагины и допустимость предметов. Скриптовые, квестовые и неподходящие объекты не становятся обычным товаром. Цены и права подтверждает сервер.

Для поддерживаемых размещённых вещей доступны витрины: цена, блокировка, покупка и управление предметом. Правила дома ограничивают действия гостей. Мебель, полученная из исходного интерьера, учитывается отдельно от коммерческой и не превращается в бесплатное золото при продаже.

### Экономика, ремесло, алхимия и квесты

Торговые коэффициенты задают стоимость покупки, продажи, обучения, зачарования и других услуг; возможны персональные настройки. Модуль Craft and Economic предоставляет региональные рынки, спрос, налоги, торговые предложения и зарегистрированные рецепты. Для содержательной экономики администратору нужно выбрать контент, заполнить рецепты и настроить правила — один запуск сервера этого не заменяет.

Системы алхимии включают изучение ингредиентов, приготовление смесей и поддерживаемое нанесение яда. Серверные квесты могут содержать этапы, цели, награды и переводы; персональное квестовое состояние позволяет управлять прохождением в общем мире. Работа конкретного квеста или рецепта зависит от подключённых модулей и плагинов.

Сложная политика, масштабные перевозки и все предлагаемые погодные сценарии относятся к дальнейшему развитию, пока не реализованы отдельным модулем. Подробнее: [игровые системы](docs/guide/04-gameplay.md), [экономика](docs/craft-economic/README_RU.md), [алхимия](docs/ARENAMP_REFINED_ALCHEMY.md), [планы](ROADMAP_RU.md).


### Движение, интерфейс и язык

Настройка `[Game] npc player passage scale` регулирует горизонтальную дистанцию между NPC и игроком при движении; она не уменьшает боевой хитбокс или столкновения с миром. Анимации, быстрые действия и меню помогают выполнять распространённые операции без набора длинных команд.

Интерфейс ArenaMP и мебельный каталог поддерживают **RU/EN**. Язык интерфейса, язык сообщений сервера и язык игровых плагинов — разные вещи: переключение меню не переводит содержимое стороннего ESM. Пользовательские имена сохраняются. Для новых предметов из модов администратор может заполнить оба названия в редакторе мебели; если английский перевод отсутствует, используется ID предмета, а не русское имя под видом перевода.

### Встроенный Rubic0n LuaJIT

Rubic0n LuaJIT теперь поставляется **полностью вместе с проектом**; скачивать обычную версию LuaJIT из другого репозитория или переходить на системную не требуется. Windows собирает эти исходники через MSVC, Linux — через локальную POSIX-сборку. Заголовок `src/luajit.h` **генерируется во время компиляции**: отсутствие его до сборки не является ошибкой. Настоящий `extern/LuaJIT/src/Makefile` обязан попасть в Git; для него исправлен `.gitignore`. После `git add -A` запустите `python3 CI/verify-rubic0n-vendor.py` для проверки индекса Git.

## GitHub Actions: Release-сборка и публикация

Зайдите в **Actions → Build and release (Windows, Linux) → Run workflow**, отметьте Windows/Linux, затем при необходимости установите **`publish_release`** и задайте **`release_tag`**. Все пакеты собираются в **Release**, а для OpenSSL в Windows применяется специальный **vcpkg-triplet только Release**, без сборки Debug-библиотек. Результаты обычного запуска доступны в **Actions**; при отмеченной публикации или отправке тега `v*` успешные сборки попадают во вкладку **Releases**.

В выпуск включаются архивы выбранных платформ, исходный снимок коммита без приватных файлов подписи, метаданные сборки и контрольные суммы. Ошибка хотя бы одной выбранной платформы блокирует общую публикацию. Если имя тега вручную не задано, используется уникальное имя по номеру запуска. Для публикации нужны разрешения записи `GITHUB_TOKEN`, установленные политиками репозитория. Полную инструкцию смотрите в [документации сборки](docs/BUILDING_RU.md).

## Совместимость, данные, безопасность

- **Данные Morrowind:** игровой контент и необходимые моды приобретаются/устанавливаются отдельно; клиенту нужен правильный порядок файлов и требуемые хеши.
- **Протокол:** ArenaMP не обязан подключаться к обычному TES3MP или другому форку; используйте клиент и сервер одной ревизии. Идентификатор версии описан в [`Version.hpp`](components/openmw-mp/Version.hpp).
- **Сохранения:** храните живые аккаунты, данные мира, домов и мебели вне публичного Git. Делайте резервные копии до обновления.
- **Проверки обновлений:** сначала испытайте новую сборку на копии мира с несколькими игроками: вход, переподключение, смена ячеек, экипировка NPC, бой, мебель, жильё и голос.
- **Диагностика:** [известные проблемы](docs/guide/09-troubleshooting.md), [руководство сервера](docs/guide/05-server.md), [статус проверки](PACKAGE_STATUS.md), логи GitHub Actions. Полная облачная сборка и игровое испытание не выполнялись в среде подготовки этих архивов.
