The new Craft and Economic implementation is original ArenaMP code, distributed under **GPL-3.0-or-later**. It builds on the OpenMW/TES3MP/ArenaMP source tree and retains its notices. The fixed legacy TES3 effect flags are shared with this tree's `components/esm/loadmgef.cpp` (OpenMW). The project licence and existing credits/notices accompany these documents in the client distribution.

The following projects informed the requested feature ideas. This is an acknowledgement, not a claim that their code is bundled, relicensed, endorsed by their authors, or covered by ArenaMP's GPL:

- **Enchanting Remastered / Enchanting UI Lua OpenMW**, by **tachyonhiggs**: <https://www.nexusmods.com/morrowind/mods/59279>; repository <https://github.com/tachyonHiggs/enchanting_ui_lua_OpenMW>. Inspiration: easier selection and editing in an enchanting interface.
- **Economy Plus — Taxes, Trade, Mercantile Perks, Fences**, by **zenocite**: <https://www.nexusmods.com/morrowind/mods/60369>. Inspiration: regional markets, taxes, trading perks, consignment and merchant investment.

The supplied mod archives did not establish a GPL-3 licence for either mod.
