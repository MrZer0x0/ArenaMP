# Android arm64: полный комплект

[Главная](../README_RU.md) · [English](../README.md)

Каталог `android/` содержит исходники приложения, редактор сенсорного управления, Gradle wrapper, сборочные сценарии и прежние файлы подписи. В каноническом движке восстановлены AndroidPath, android_main.cpp, JNI локального сервера и Android-ветки CMake. Они не заменяют десктопные цели на Windows/Linux.

## Сборка

Разместите содержимое каталога ArenaMP в корне закрытого репозитория вместе с .github, android, apps, components и extern. Сохранённые Android-ключи предназначены для прежнего личного репозитория; проверка приватности и проверка отпечатка сертификата сохранены. В Actions запустите Build and release (Windows, Linux, Android) с включённым build_android. Для отдельной проверки APK отключите build_windows и build_linux.

Задача Android подготавливает SDK, JDK и нативный toolchain по прежнему рецепту, проверяет ресурсы, подпись и встроенные клиент/сервер. APK после успешной сборки доступен в Artifacts под именем ArenaMP-Android-arm64-ClientServer. Наличие исходников не означает наличия уже собранного APK.

Новые идентификаторы кеша исключают восстановление старых объектных файлов физики. Первый запуск будет холодным. Финальный этап подготовки обновляет 279 файлов, включая все интерфейсы механики, объявления физических типов и настройки прохода. Устаревшие actorbodyrules.hpp и playerbodyshape.hpp удаляются из кешированного staging. Полная проверка `--verify-only` должна завершиться без изменений.

Автоматическая публикация настольных выпусков сохранена для закрытого репозитория. APK выгружается отдельным артефактом. Эта задача не создаёт публичную публикацию личного архива с ключами.

## Проверки

Выполнены подготовка и проверка паритета исходников Android, проверка цветов ресурсов, компиляция и запуск реальной функции прохода в изолированном тесте, проверки отката физики и сохранённых методов инструментов. Полный NDK/Gradle билд APK, Windows/Linux билд и игровой сеанс здесь не выполнялись.
