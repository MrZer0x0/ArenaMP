# Подготовка публичного репозитория

1. Распакуйте архив в отдельную папку.
2. Скопируйте содержимое `ArenaMP/` в корень рабочей копии GitHub-репозитория. Включите `.github`, `.gitignore`, `.gitattributes`, `extern/` и `server/`.
3. Если заменяете другое дерево исходников, используйте чистую рабочую копию и заранее сохраните свои изменения. Не переносите рабочие профили и мир из игрового сервера.
4. Выполните `git add -A`, затем `python3 CI/verify-rubic0n-vendor.py`. Убедитесь, что Makefile из `extern/LuaJIT/src/` входит в индекс.
5. Создайте коммит и отправьте его в `main` или `master`. Включите Actions и разрешите задаче выпуска запись содержимого репозитория.
6. Откройте Actions и дождитесь результата. При успехе выбранных платформ пакеты автоматически появятся в Releases.

Для ручного выбора платформ используйте Run workflow. Для собственного имени версии отправьте тег `v*`. Устройство workflow, состав файлов и локальная сборка описаны в [BUILDING_RU.md](BUILDING_RU.md).
