## Что приложить к отчёту

Укажите коммит или тег, ОС, оборудование, клиентскую и серверную конфигурацию, плагины и порядок, шаги воспроизведения и журналы. Отделите проблему чистого профиля от проблемы сохранённого мира. Уберите пароли и личные данные из публикуемого журнала.

## Сборка и выпуск

| Проблема | Проверка |
|---|---|
| Не найден `CI/verify-rubic0n-vendor.py` | Команда должна запускаться из корня репозитория; весь `CI/` должен быть закоммичен |
| Не найден `extern/LuaJIT/src/Makefile` | Проверить индекс Git и правила `.gitignore`, повторно добавить полное дерево LuaJIT |
| В исходниках нет `luajit.h` | Это генерируемый файл; проверяются исходники, а заголовок ожидается после компиляции |
| Нет внешних CMake-каталогов | Проверить комплектность `extern/` и запустить `CI/ensure-bundled-deps.sh` |
| Ошибка загрузки зависимости | Изучить URL, код ответа и журнал; временный сбой источника не исправляется изменением кода игры |
| Артефакт собран, но Release отсутствует | Проверить все выбранные задачи и задачу публикации; ей нужна разрешённая запись содержимого репозитория |
| Выпуск остался черновиком | Загрузка файлов не завершилась; черновик не публикуется частично |
| Существует выпуск с таким тегом | Для нового выпуска использовать новый тег |

## Лаунчер и сеть

Пустой список требует проверки мастер-адреса, HTTPS и доступности сервиса. Для туннеля нужен relay-агент из полного пакета. Для прямого соединения проверьте адрес, UDP-порт и брандмауэр. Запуск локального сервера диагностируется по встроенной консоли.

Ошибки Qt в Linux проверяйте при запуске через обёртку и комплектные библиотеки. Ошибки обновления — по `Update.log` и манифесту выбранной сборки.

## Игровые состояния

- **Возврат не перемещает:** проверить Пометку, членство в группе, доступность цели и запреты путешествий.
- **Призыв произносит заклинание без эффекта:** проверить запись заклинания, магию, цель и владельца сетевой ячейки.
- **Зависание при входе в дом:** сопоставить время клиента и сервера, проверить реестр экземпляров и пути/контент. Не создавать новые экземпляры повторными попытками без анализа журнала.
- **Пропала мебель:** проверить активные плагины, каталоги мебели и сохранённые реестры, восстановить согласованный бэкап при необходимости.
- **Инструмент или экипировка восстановились неверно:** указать ID, состояние экземпляров, способ активации и момент ручной смены предмета.
- **Сложно пройти лестницу:** приложить название ячейки, положение, расу, рост/масштаб и направление движения. Изолированные геометрические тесты не охватывают все игровые лестницы.

## Сидение на стуле

Сообщение о персонаже, зависающем над стулом при сидячей анимации, остаётся открытой проблемой. Нужна проверка высоты/смещения конкретной анимации и модели мебели в собранном клиенте. Этот выпуск не заявляет решение этой проблемы.

## Границы выпуска

Исходники не являются доказательством успешной полной компиляции или проверки всех игровых сценариев. Статус подготовки — в [PACKAGE_STATUS.md](../../PACKAGE_STATUS.md). Перед игровым развёртыванием нужны полные сборки и сессия с несколькими клиентами.
