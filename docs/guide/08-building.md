# Сборка исходников

[Оглавление](INDEX.md)

Основные инструкции: [русский](../BUILDING_RU.md) / [English](../BUILDING.md).

Публичные пакеты предназначены для Windows x64 и Linux x86_64 / Steam Deck. Workflow собирает Release, проверяет установленное дерево и автоматически публикует результат после успеха всех выбранных платформ. Отдельная галочка публикации не нужна.

Для своего имени версии используйте тег `v*`. Для обычного запуска создаётся уникальный тег сборки. В Releases входят бинарные пакеты выбранных платформ, архив исходников этого коммита, сведения о сборке и SHA-256. Диагностические журналы доступны в Actions.

Требуемые условия репозитория, выбор платформ и локальные команды находятся в основном руководстве. Состав зависимостей — в [реестре](DEPENDENCY_PROVENANCE.md), границы проверки — в [валидации](VALIDATION.md).
