# Происхождение зависимостей

[Оглавление](INDEX.md)

В `extern/` находятся включённые исходники сетевых, мультимедийных и служебных библиотек. Состав и контрольные суммы описаны в `extern/ARENA_DEPENDENCY_SOURCES.json`. Основой части дерева служит TES3MP 0.8.1, commit `68954091c54d0596037c4fb54d2812313b7582a1`; интеграция maskedoc закреплена на `9c049b971a6e336be25bec2898dd729bdba6f458`.

Rubic0n LuaJIT находится в `extern/LuaJIT/`; его происхождение описано в `extern/LuaJIT/.arenamp-upstream.txt`, а обязательная проверка комплекта — `CI/verify-rubic0n-vendor.py`. Авторские условия находятся в `extern/LuaJIT/COPYRIGHT`. Генерируемые заголовки появляются при сборке.

Системные библиотеки, инструменты и загружаемые во время сборки проекты задаются платформенными сценариями CI. Сохраняйте журнал запуска: он связывает используемый инструментальный набор с исходниками и пакетом. Для воспроизводимости внешнего проекта нужен его точный commit, а не одно имя ветки.

Исходники зависимостей хранятся обычными файлами Git. Вложенный репозиторий не должен скрывать их содержимое. Перед отправкой выполните `git add -A`, проверку LuaJIT и `CI/ensure-bundled-deps.sh`. Не удаляйте исходные COPYRIGHT, LICENSE и NOTICE.
