# Карта исходников

[Оглавление](INDEX.md)

| Область | Каталог или файл |
|---|---|
| Версия и сетевой протокол | `components/openmw-mp/Version.hpp` |
| Игра | `apps/openmw/` |
| Клиентская сеть | `apps/openmw/mwmp/`, `components/openmw-mp/` |
| Нативный сервер и Lua API | `apps/openmw-mp/` |
| Бой, магия, управление анимациями | `apps/openmw/mwmechanics/` |
| Игровой интерфейс и ввод | `apps/openmw/mwgui/`, `apps/openmw/mwinput/` |
| Лаунчер и настройка сборки | `apps/launcher/` |
| Нативный обновлятор | `apps/launcher/updater/` |
| Серверный и relay-агенты | `apps/launcher/agent-native/` |
| Общие компоненты | `components/` |
| Серверные системы | `server/scripts/` |
| Стартовые данные сервера | `server/data/` |
| Интерфейс, шейдеры, VFS | `files/` |
| Сторонние исходники и Rubic0n LuaJIT | `extern/` |
| Сборка и публикация | `CI/`, `.github/workflows/release-builds.yml` |
| Проверки | `tests/` |

Названия некоторых тестовых каталогов отражают внутренние идентификаторы разработки. Это имена наборов проверок, а не самостоятельные публичные релизы.

Для пользовательского поведения читайте руководство, для конкретных значений — реализацию и конфигурацию. При изменении системы согласованно обновляйте её код, серверные правила, ресурсы, перевод и соответствующий документ.

Уведомления авторов, исходные лицензии и справочники включённых проектов сохраняются рядом с их материалами. Отдельные игровые расширения EncoreMP находятся в `extras/encoremp/`.
