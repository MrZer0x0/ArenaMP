# Установка и первый запуск

[Оглавление](INDEX.md) · [Лаунчер](../LAUNCHER_RU.md)

## Что потребуется

Готовый пакет из успешной сборки, собственные данные Morrowind и набор плагинов выбранного сервера. Клиент и сервер должны использовать совместимую ревизию ArenaMP и одинаковый контент. Исходный архив сначала нужно [скомпилировать](../BUILDING_RU.md).

## Windows

Распакуйте ZIP целиком в папку с правом записи. Запустите `arenamp-launcher.exe`. Сохраните рядом обновлятор, агентов, библиотеки и ресурсы. Укажите папку игровых данных в мастере сборки.

## Linux и Steam Deck

Распакуйте переносимый `.tar.gz` с сохранением прав исполнения. Запускайте обёртку `./arenamp-launcher`: она подготавливает окружение библиотек и Qt. На Steam Deck выполняйте первоначальную настройку в режиме рабочего стола; затем можно добавить обёртку в Steam как стороннюю игру.

Пакет использует согласованный Qt5 и путь XCB/Xwayland. Графический драйвер остаётся частью системы. Не смешивайте библиотеки из разных пакетов вручную.

## Выбор контента и сервера

Выберите папку с `Morrowind.esm`, проверьте `build.ini`, плагины и их порядок. Для нового набора мастер может создать манифест. Выберите сервер из списка либо введите адрес и порт. При необходимости введите пароль и нажмите Играть.

EncoreMP ESP из `extras/encoremp/` подключаются по решению владельца сервера. Наличие ESP в исходниках не означает, что все они должны быть включены одновременно.

Создайте персонажа в игре. Его учётная запись используется для входа в совместимый чат лаунчера. Прочитайте внутриигровое обучение и проверьте сохранённые клавиши.

## Обновления и данные

Игровой обновлятор использует адреса и манифесты выбранной сборки. Перед ручной заменой пакета закройте клиент, лаунчер и сервер. Сохраните конфигурацию и резервную копию игровых данных сервера. Не заменяйте рабочие профили стартовыми файлами из исходного дерева.

При проблеме приложите ревизию исходников, ОС, порядок контента и журналы клиента/сервера. См. [диагностику](09-troubleshooting.md).
