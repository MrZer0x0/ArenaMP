# Проверка первого публичного выпуска

[Оглавление](INDEX.md) · [Статус исходников](../../PACKAGE_STATUS.md)

## Уровни проверки

| Уровень | Что он подтверждает |
|---|---|
| Комплектность и документация | Наличие исходников/зависимостей, локальных ссылок и необходимых файлов |
| Изолированные регрессии | Поведение конкретных функций, скриптов и геометрических сценариев |
| Полная платформенная сборка | Совместимость компилятора, линковки, установки и упаковки |
| Игровая сессия | Работа реального контента, GUI, анимаций и сетевого взаимодействия |

Успех одного уровня не заменяет остальные.

## Локальные проверки исходного дерева

Для подготовки этого комплекта выполнены проверки состава LuaJIT, структуры Windows/Linux workflow, shell-синтаксиса, локальных ссылок и целостности архива. Подготовка release-файлов проверяется отдельно на искусственных бинарных пакетах без публикации в GitHub.

Для игрового кода в этом исходном дереве проходили изолированные проверки автоматических инструментов, восстановления экипировки, цен/инвентаря, стамины и точки входа Linux. Геометрические сценарии новой оболочки и тесты нового кеша OpenSSL удалены вместе с откатанными реализациями; их прежние результаты не относятся к текущему состоянию.

## Команды отдельных наборов

```bash
python3 CI/verify-rubic0n-vendor.py
python3 tests/release/test_prepare_release.py
python3 tests/avatar_security/run_checks.py
python3 tests/v18/run_checks.py
python3 tests/collision_baseline/run_checks.py
python3 tests/npc_passage/run_checks.py
python3 tests/launcher/linux_start_test.py
```

Для нативных изолированных проверок нужен C++17. Часть проверок использует тестовые замены движка или извлечённые методы. Другие наборы в `tests/` имеют собственные зависимости; их присутствие не означает выполнения всех проверок.

## Проверка собранного пакета

Полная сборка Windows и Linux в рамках подготовки архива не выполнялась. После запуска Actions убедитесь, что прошли оба выбранных задания и проверка пакетов. Проверьте содержимое Releases и SHA-256.

Перед развёртыванием выполните сессию с двумя клиентами: подключение, смена ячейки, переподключение, голос, бой, инструменты, покупка/размещение мебели, повторный вход и перезапуск сервера. Испытайте проблемные лестницы и стулья на реальном контенте. Открытые вопросы перечислены в [диагностике](09-troubleshooting.md).
