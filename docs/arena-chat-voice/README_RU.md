# Чат и голос ArenaMP

[Лаунчер](../LAUNCHER_RU.md) · [Управление](../guide/02-controls.md)

## Компоненты

| Компонент | Реализация |
|---|---|
| Постоянное соединение чата лаунчера | `apps/launcher/arenalinkclient.*`, `chatpage.*` |
| Сервер чата и игровой учётной записи | `apps/openmw-mp/LinkServer.*`, `LinkAccountStore.*` |
| Общий формат сообщений и входа | `components/openmw-mp/arenalink.hpp`, `arenalinkauth.hpp` |
| Серверная маршрутизация голоса | `apps/openmw-mp/VoiceServer.*` |
| Формат голосовых пакетов | `components/openmw-mp/arenavoice.hpp` |
| Устройство и голосовой контроллер лаунчера | `apps/launcher/voice/` |
| Связь состояния игры и лаунчера | `apps/openmw/mwmp/VoiceBridge.*` |

Чат и голос имеют отдельные сетевые службы. Настройки портов задаются сервером; типовая схема использует игровой порт, следующий UDP-порт для голоса и следующий TCP-порт для чата. Не считайте все серверы доступными по одному фиксированному набору портов.

## Вход и чат

Используется существующий персонаж игрового сервера. Создание персонажа выполняется в игре. Лаунчер показывает каналы, историю, присутствие, упоминания и статус соединения по данным совместимого сервера. Журнал доступен через Chat.log.

Проверки учётной записи и возможностей должны выполняться сервером. Не помещайте пароли, токены и закрытые профили в диагностические сообщения. Служебный протокол не равен произвольному разрешению выполнять команды сервера.

## Голос

Лаунчер выбирает устройство записи и клавишу, включает или отключает передачу. Игровое состояние задаёт участие в локальном/групповом общении и индикацию. Воспроизведение входящих участников не должно считаться включением своего микрофона.

На доступность влияют серверные параметры, сетевые порты, наличие устройств и согласованность клиентских компонентов. Обработка звука и качество должны проверяться с реальными устройствами.

## Проверка

Используйте два игровых аккаунта и два клиента. Проверьте вход в чат, каналы, сообщения, историю, выход/переподключение, смену устройства, запрет микрофона и локальный/групповой разговор. Изолированные проверки находятся в `tests/voice`, `tests/arena-voice` и `tests/arena-link`, где соответствующие каталоги присутствуют в дереве.
