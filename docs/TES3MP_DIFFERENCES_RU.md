# ArenaMP и TES3MP

[English project overview](../README.md) · [Русское описание](../README_RU.md)

ArenaMP develops the OpenMW/TES3MP/EncoreMP foundation with its launcher, combat, voice, housing and economy systems. Use the project overview and [documentation index](guide/INDEX.md) for the public release's capabilities. Compatibility requires matching client/server revisions and content; shared ancestry does not guarantee compatibility with another fork.
