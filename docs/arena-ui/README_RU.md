# Интерфейс настольных приложений ArenaMP

[Лаунчер](../LAUNCHER_RU.md)

## Оформление

Лаунчер, связанные диалоги и обновлятор используют общие Qt-компоненты темы. Палитра сочетает тёмную основу, тёплый текст и золотые акценты. Отрисовка рамок, скруглений, теней и элементов управления включена в исходники приложения.

Главный экран содержит навигацию по игре, файлам данных, графике, чату и настройкам. В игровой части находятся подключение, серверный каталог, консоль и настройки собственного сервера. Карточка состояния показывает оборудование, выбранное соединение и состояние обновления/сервера.

## Разработка интерфейса

Общие элементы находятся в `components/misc/arenatheme.hpp` и `arenaglasswindow.hpp`. При изменении компоновки сохраняйте имена виджетов, используемые сигналами, настройками и тестами. Применяйте общий стиль к кнопкам, спискам, вкладкам и редакторам вместо отдельных несовместимых оформлений.

Оставляйте место длинным русским подписям и сообщениям об ошибке. Проверяйте навигацию с клавиатуры, масштабирование ОС, прокрутку формы и читаемость неактивных состояний. Платформенные эффекты композитора не должны быть условием работы интерфейса.

## Проверка

Проверяйте запуск, выбор сборки, все страницы, консоль длинного журнала и окно обновления. Наборы `apps/launcher/updater/qt-tests` и `components/misc/arena-ui-tests` проверяют отдельные жизненные циклы Qt. Они не заменяют визуальную проверку полного пакета.
